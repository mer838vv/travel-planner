# Travel Planner

Личный планировщик поездок. PWA — ставится на телефон как приложение,
все данные хранятся локально в браузере (IndexedDB), без сервера и логина.

**Опубликовано:** https://mer838vv.github.io/travel-planner/

Репозиторий публичный (бесплатный тариф GitHub не даёт Pages на приватных),
но личных данных в нём нет: поездки, билеты и файлы никогда не покидают
устройство, на котором введены. Публичен только код приложения.

## Возможности

- **Маршрут**: дни поездки, точки интереса на карте (OpenStreetMap) с описанием, временем, длительностью и стоимостью
- **Билеты**: хранилище билетов и документов (авиа, отель, страховка, виза) с прикреплёнными файлами
- **Сборы**: чек-лист вещей по категориям со стандартным шаблоном
- **Бюджет**: расходы по категориям и валютам с итогами
- **Погода**: прогноз на даты поездки в месте назначения (Open-Meteo, бесплатно)
- **План от агента**: Claude со скиллом `trip-plan` собирает поездку (перелёт, жильё, места, погода) и выдаёт готовый план — он вставляется в приложение одной кнопкой и заполняет маршрут, билеты, вещи и бюджет. Формат описан в [AGENT_FORMAT.md](AGENT_FORMAT.md)
- Работает офлайн после первого открытия (service worker кеширует приложение и тайлы карты)
- Экспорт/импорт бэкапа в JSON — перенос данных между устройствами

## Запуск

```
npm install
npm run dev
```

Открой `http://localhost:5173`, в мобильном браузере — «Добавить на экран Домой»,
чтобы приложение вело себя как обычное.

## Тесты

```
npm test
```

`node --test`, база подменяется на `fake-indexeddb` — сети и реального
браузера тесты не требуют. Покрыт приём плана от агента: раскладка по
таблицам, отказ на мусоре, пропуск битых записей, неприкосновенность уже
существующих поездок.

## Сборка

```
npm run build
npm run preview
```

## Публикация обновлений

```
npm run deploy
```

Собирает с `BASE_PATH=/travel-planner/` и заливает `dist` в ветку `gh-pages`,
откуда GitHub Pages раздаёт сайт. Обновление на устройстве подхватывается само
(service worker в режиме `autoUpdate`) при следующем открытии с сетью.

## Технологии

React + Vite, Dexie (IndexedDB), react-leaflet + OpenStreetMap, Open-Meteo,
Nominatim (геокодинг), vite-plugin-pwa. Без бэкенда — всё локально на устройстве.
