# Travel Planner

Личный планировщик поездок. PWA — ставится на телефон как приложение,
все данные хранятся локально в браузере (IndexedDB), без сервера и логина.

## Возможности

- **Маршрут**: дни поездки, точки интереса на карте (OpenStreetMap) с описанием, временем, длительностью и стоимостью
- **Билеты**: хранилище билетов и документов (авиа, отель, страховка, виза) с прикреплёнными файлами
- **Сборы**: чек-лист вещей по категориям со стандартным шаблоном
- **Бюджет**: расходы по категориям и валютам с итогами
- **Погода**: прогноз на даты поездки в месте назначения (Open-Meteo, бесплатно)
- Работает офлайн после первого открытия (service worker кеширует приложение и тайлы карты)
- Экспорт/импорт бэкапа в JSON — перенос данных между устройствами

## Запуск

```
npm install
npm run dev
```

Открой `http://localhost:5173`, в мобильном браузере — «Добавить на экран Домой»,
чтобы приложение вело себя как обычное.

## Сборка

```
npm run build
npm run preview
```

## Технологии

React + Vite, Dexie (IndexedDB), react-leaflet + OpenStreetMap, Open-Meteo,
Nominatim (геокодинг), vite-plugin-pwa. Без бэкенда — всё локально на устройстве.
