# Формат плана от агента

Приложение — статика на GitHub Pages без бэкенда. Ключ от Claude API сюда
вшить нельзя (сайт публичный), поэтому агент работает снаружи: исследует
поездку своими скиллами и отдаёт результат в этом формате. Пользователь
вставляет его кнопкой «Вставить план от агента» на главном экране.

Импорт всегда создаёт **новую** поездку и ничего не перезаписывает.

## Схема

```json
{
  "trip": {
    "title": "Рим, октябрь",
    "startDate": "2026-10-03",
    "endDate": "2026-10-07",
    "destinationName": "Рим, Италия",
    "destinationLat": 41.9028,
    "destinationLon": 12.4964
  },
  "days": [
    {
      "date": "2026-10-03",
      "pois": [
        {
          "name": "Колизей",
          "description": "Амфитеатр 80 года, вмещал 50 тысяч зрителей. Билет общий с Форумом, действует два дня.",
          "lat": 41.8902,
          "lon": 12.4922,
          "visitTime": "10:00",
          "durationMin": 120,
          "cost": "18 €"
        }
      ]
    }
  ],
  "tickets": [
    {
      "title": "SU2402 Москва — Рим",
      "category": "Авиабилет",
      "date": "2026-10-03",
      "note": "Багаж 23 кг включён",
      "flight": {
        "number": "SU2402",
        "pnr": "ABC123",
        "seats": ["20C", "20B"],
        "from": {
          "iata": "SVO", "name": "Шереметьево", "terminal": "C",
          "address": "Аэропорт Шереметьево", "tz": "Europe/Moscow"
        },
        "to": {
          "iata": "FCO", "name": "Рим, Фьюмичино", "terminal": "1",
          "tz": "Europe/Rome"
        },
        "departLocal": "2026-10-03T08:40",
        "arriveLocal": "2026-10-03T11:25",
        "checkinClosesLocal": "2026-10-03T07:55",
        "leaveAtLocal": "2026-10-03T05:40",
        "leaveNote": "дорога 50 мин + запас на пробки + контроль"
      }
    }
  ],
  "packing": [{ "category": "Документы", "name": "Паспорт" }],
  "budget": [
    { "title": "Отель, 4 ночи", "category": "Жильё", "amount": 420, "currency": "EUR" }
  ]
}
```

## Правила полей

| Поле | Обязательно | Замечания |
|---|---|---|
| `trip.title` | да | Любая строка |
| `trip.startDate` / `endDate` | да | Строго `ГГГГ-ММ-ДД`, конец не раньше начала |
| `trip.destinationLat` / `Lon` | нет | Без них не будет погоды и центрирования карты |
| `days[].date` | да | Дата вне диапазона поездки — день молча пропускается |
| `pois[].name` | да | Без названия точка пропускается |
| `pois[].lat` / `lon` | **да** | **Без координат точка пропускается** — она не встанет на карту |
| `pois[].description` | нет | Здесь ценность агента: чем ставить точку, лучше объяснить |
| `pois[].visitTime` | нет | Строка вида `10:00` |
| `pois[].durationMin` | нет | Число минут |
| `pois[].cost` | нет | Строка, можно с валютой: `18 €` |
| `tickets[].category` | нет | Только из списка ниже, иначе станет `Другое` |
| `tickets[].note` | нет | Номер брони, терминал, адрес заселения |
| `budget[].amount` | да | Число; строка вида `"55.5"` тоже принимается |
| `budget[].currency` | нет | По умолчанию `EUR`, приводится к верхнему регистру |

Категории билетов: `Авиабилет`, `Отель`, `Поезд/автобус`, `Музей/экскурсия`,
`Страховка`, `Виза`, `Другое`.

## Блок `flight` внутри билета

Необязателен: у страховки или музея его нет, и билет остаётся обычным
билетом. Если он есть — приложение показывает карточку ближайшего рейса с
терминалом, обратными отсчётами и проверкой стыковки.

| Поле | Обязательно | Замечания |
|---|---|---|
| `from` / `to` | да | Без обоих блок игнорируется целиком |
| `from.iata` | да | Код аэропорта, `SVO`, `FCO` |
| `from.terminal` | нет | **Самое ценное поле.** Показывается крупно: в городах с несколькими аэропортами и терминалами именно оно решает, куда ехать |
| `from.address` | нет | Идёт в кнопку «скопировать для такси»; без него берётся `name` |
| `from.tz` | **фактически да** | IANA-имя (`Europe/Rome`). **Без пояса не будет ни одного отсчёта и длительности перелёта** |
| `departLocal` / `arriveLocal` | да | **Местное** время `ГГГГ-ММ-ДДTЧЧ:ММ`, как в билете. Пересчёт в UTC приложение делает само по `tz` |
| `checkinClosesLocal` | нет | Момент закрытия онлайн-регистрации |
| `leaveAtLocal` | нет | Когда выезжать. Считает агент: дорога + пробки + контроль + запас |
| `leaveNote` | нет | Из чего сложилось время выезда — человек должен видеть логику, а не голое число |
| `pnr` | нет | Номер брони. **Разные `pnr` у соседних рейсов = раздельные билеты**, приложение отдельно предупредит о риске стыковки |
| `seats` | нет | Массив строк |

Стыковки приложение считает само по соседним рейсам: длительность, смена
аэропорта, раздельные билеты. Порог — от трёх часов для раздельных броней,
от полутора для единого билета, меньше часа или смена аэропорта — критично.

Файлы (сканы билетов) агент приложить не может — их пользователь добавляет
сам во вкладке «Билеты». Номер брони при этом стоит положить в `note`.
