# Формат плана от агента

Приложение — статика на GitHub Pages без бэкенда. Ключ от Claude API сюда
вшить нельзя (сайт публичный), поэтому агент работает снаружи: исследует
поездку своими скиллами и отдаёт результат в этом формате. Пользователь
вставляет его кнопкой «Вставить план от агента» на главном экране.

Импорт всегда создаёт **новую** поездку и ничего не перезаписывает.

## Схема

```json
{
  "trip": {
    "title": "Рим, октябрь",
    "startDate": "2026-10-03",
    "endDate": "2026-10-07",
    "destinationName": "Рим, Италия",
    "destinationLat": 41.9028,
    "destinationLon": 12.4964
  },
  "days": [
    {
      "date": "2026-10-03",
      "pois": [
        {
          "name": "Колизей",
          "description": "Амфитеатр 80 года, вмещал 50 тысяч зрителей. Билет общий с Форумом, действует два дня.",
          "lat": 41.8902,
          "lon": 12.4922,
          "visitTime": "10:00",
          "durationMin": 120,
          "cost": "18 €"
        }
      ]
    }
  ],
  "tickets": [
    {
      "title": "Рейс SU2402 Москва — Рим",
      "category": "Авиабилет",
      "date": "2026-10-03",
      "note": "Вылет 08:40, бронь ABC123, багаж 23 кг включён"
    }
  ],
  "packing": [{ "category": "Документы", "name": "Паспорт" }],
  "budget": [
    { "title": "Отель, 4 ночи", "category": "Жильё", "amount": 420, "currency": "EUR" }
  ]
}
```

## Правила полей

| Поле | Обязательно | Замечания |
|---|---|---|
| `trip.title` | да | Любая строка |
| `trip.startDate` / `endDate` | да | Строго `ГГГГ-ММ-ДД`, конец не раньше начала |
| `trip.destinationLat` / `Lon` | нет | Без них не будет погоды и центрирования карты |
| `days[].date` | да | Дата вне диапазона поездки — день молча пропускается |
| `pois[].name` | да | Без названия точка пропускается |
| `pois[].lat` / `lon` | **да** | **Без координат точка пропускается** — она не встанет на карту |
| `pois[].description` | нет | Здесь ценность агента: чем ставить точку, лучше объяснить |
| `pois[].visitTime` | нет | Строка вида `10:00` |
| `pois[].durationMin` | нет | Число минут |
| `pois[].cost` | нет | Строка, можно с валютой: `18 €` |
| `tickets[].category` | нет | Только из списка ниже, иначе станет `Другое` |
| `tickets[].note` | нет | Номер брони, терминал, адрес заселения |
| `budget[].amount` | да | Число; строка вида `"55.5"` тоже принимается |
| `budget[].currency` | нет | По умолчанию `EUR`, приводится к верхнему регистру |

Категории билетов: `Авиабилет`, `Отель`, `Поезд/автобус`, `Музей/экскурсия`,
`Страховка`, `Виза`, `Другое`.

Файлы (сканы билетов) агент приложить не может — их пользователь добавляет
сам во вкладке «Билеты». Номер брони при этом стоит положить в `note`.
